Dashboard Sections

  • Camera Feed — Live MJPEG stream with face ovals (green) and object boxes (cyan).
  • Telemetry — Temperature, fan duty, servo angle, microphone level, and last spoken text.
  • Services — Live status of each internal service. Use ⟳ to restart the daemon.
  • Face Registry — Known faces with thumbnails, seen counts, and merge/delete actions. Click a thumbnail to enlarge.
  • Controls — Say text, pan servo, toggle tracking, adjust travel limits, speak version, describe scene.
  • Greeting Settings — Configure face greeting cooldown, jitter, minimum absence, and confidence threshold.
  • Music (Pandora) — Play, pause, skip, love/ban songs, and select stations via pianobar.
  • Quiet Hours — Suppress TTS announcements during a configured time window.
  • Event Log — Last 20 bus events (newest first).
  • System Power — Reboot or shut down the Pi from the browser.

Object Detection

Detects 80 COCO classes (person, laptop, cup, etc.) at ~3 fps using YOLOv8s on Hailo-8. Cyan rectangles show detected objects; green ovals show recognized faces. Click Describe What I See to have DA speak a summary.
